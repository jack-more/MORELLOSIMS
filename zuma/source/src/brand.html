Brand guide

ZUMA, built from four colors.

The rules for everything ZUMA makes: colour, the bands, how a visitor knows where to click, layout, type, the label and the research-use line. The shop is built from these files: design/tokens.json (every value), css/ui.css (every component) and this text (design/brand-guide.md).

Palette

Four areas, three tones each. Then the house.

Area colours belong to their compounds only. Every control, section ground and the token program use the house colours.

The guide

For developers

Where everything lives

One source per thing. Change it there and the shop, the labels and the guide follow.

Values

design/tokens.json

Every colour, type style, space, radius, shadow and layer. build.py compiles it to CSS custom properties (--ink, --metabolic-bright, --space-6…) and one class per type style (.display-l, .lead…).

Components

css/ui.css

Grounds (.z-paper, .z-sand, .z-ink, and the bands .z-light, .z-bright, .z-deep inside data-area), buttons, links, chips, tags, cards, tiles, panels, controls, tables and the referral ladder.

The logo

logo-slot.svg

The only copy of the logo, a <symbol id="zuma-logo" viewBox="0 0 320 100"> inlined on every page. Every use is <svg><use href="#zuma-logo"/></svg>, and the 3D labels redraw the same symbol. The final logo replaces the symbol's contents.

The same rules, with live examples of every component, are in the ZUMA design system on claude.ai. Page layout that is specific to the shop lives in css/site.css.
