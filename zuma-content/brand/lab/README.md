# ZUMA lab (12 Nov 2026)

A post-modern, mission-style concrete lab: deep round-arched openings in a raw concrete wall, each glazed with one research-area
Lightbox (ombre.js renders: Oxblood bars straight, palm behind the glass), a monolithic concrete plinth with real ZUMA vials
(zuma/render/vial.py), a thin haze so the window colour hangs in the air.

- `source/lab.py`: the scene (Blender/Cycles via bpy). Concrete: Poly Haven CC0 `concrete_wall_008`, `concrete_floor_02` (2k).
- Styleframe settings: WSCALE=0.0028 FOG=0.00022 AH=520 RH=640 SPACE=240 LBSTR=2.6 LENS=22 CDIST=36 CZ=101.5 TZ=300 FSTOP=4 FILL=900000 RIM=2500000,
  WINDOWS=tissue,metabolic,neuro, LABVIALS=05@-7,01@0,11@7, 1080 x 1920, 160 samples.
