# Compound stickers

One sticker per product, Snow with the name in Oxblood. They name what is inside the bag and the box.

- `print/zuma-sticker-bag-NN.pdf`: 26.0 x 10.0 mm, corners 1.6 mm, name + research area (BAC water: Bacteriostatic water). For the vacuum bag.
- `print/zuma-sticker-box-NN.pdf`: 14.0 x 6.0 mm, corners 1.0 mm, name only. For the box front.
- Every file has 1 mm bleed (page 28 x 12 mm and 16 x 8 mm). Die-cut on the rounded rectangle at trim, no border. 1016 dpi.
- `stickers-proof.jpg`: all 24 with the cut line in pink (the print files carry no lines).

NN is the catalog number: 01 RT-3, 02 TZ-2, 03 BAC water, 04 Tesamorelin, 05 GHK-Cu, 06 MOTS-c, 07 CJC+IPA, 08 NAD+, 09 BPC+TB, 10 KLOW, 11 Selank, 12 Semax.
Order kiss-cut on sheets or rolls; matte white vinyl or paper with a matte laminate.
