Vial specification

Three versions, in order of preference. Option A: transparent colour spray coating on clear vials, one colour per category, Oxblood screen print, Oxblood cap. Option B: plain clear vials, Oxblood screen print, flip-off cap in the category colour. Option C: plain clear vials with a printed wrap label, Oxblood cap. Print artwork is supplied as true-size vector PDF.
